## 二、本地真机验证（**最关键，别跳**）

**这一步不能在自己平时用的浏览器里做** —— 那个配置早就开好了内置模型的开关，
看不到新用户（和审核员）看到的东西。

最省事的办法是双击：

```
tools\test-fresh.cmd
```

它会建一个**全新的浏览器配置**（没开过任何 flag）并加载扩展，
然后打印逐项检查清单。临时配置放在 `%TEMP%`，不影响你原来的浏览器。

手动做也可以：

```
用 --user-data-dir 起一个新的 Edge：
  msedge.exe --user-data-dir="%TEMP%\fresh" --load-extension="<扩展目录>" --new-window
然后在新窗口里 edge://extensions → 开发人员模式 → 加载解压缩的扩展
```

**还有一个更快的办法**（不用新配置）：
在「API 设置」里切换到任意**云端后端**并清空 key，保存 ——
引导条会立刻出现（它现在也管"选了云端但没填 key"这种情况）。
切回内置模型就消失。

- [ ] 图标显示正常（不是默认灰色拼图）
- [ ] 点图标 → 侧栏出现引导条或开始读取
- [ ] **没开内置模型 flag 的环境下**，看到的是引导条（而不是一句报错）
- [ ] 点【怎么开启内置模型】→ 出现开启步骤
- [ ] 点【换成云端后端】→ 打开 API 设置
- [ ] 打开一篇英文文章 → 按空格 → 出讲解
- [ ] 打开一个 PDF → 段落分段正常
- [ ] 术语行有解释、来源标记正确

> **这一节必须在"没开过 flag 的配置"里做一次** ——
> 审核员就是这个环境，第一印象决定过不过。

## 被拒了怎么办

**最常见的三种拒绝理由，以及对应做法：**

| 拒绝理由 | 怎么办 |
|---|---|
| **权限过宽** | 把 `permissions.md` 里那段理由**完整**填进表单（多数情况是没填清楚）。若仍被要求收窄，改成只申请 `activeTab`，代价见该文档末尾。 |
| **隐私政策缺失或内容不符** | 确认 URL 可访问、内容和扩展实际行为一致。特别注意表单勾选项与实际不要矛盾。 |
| **功能描述与实际不符** | 检查文案里有没有承诺做不到的事。本项目的 `listing.md` 已主动列出"已知限制"，一般不会踩这条。 |
