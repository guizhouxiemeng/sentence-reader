隐私政策 · 按句读（阅读辅助）

最后更新：2026-10-10　·　适用版本：1.0.0 及以上
这个扩展不收集、不上传、不存储你的任何个人数据。
它唯一会「往外发」的东西，是你主动按空格求助时那一句话的正文 —— 而且只发给你自己配置的那个 AI 服务，不经过我们。

1. 我们不收集什么

  • 不收集浏览历史
  • 不收集账号、邮箱、手机号
  • 不收集设备信息、位置
  • 不埋点、不做统计、不做 A/B 测试
  • 没有自己的服务器，所以也没有「数据传回我们这里」这回事

2. 扩展会读到什么

为了把文章按句切开并高亮，扩展需要在网页上读取正文文字。

  • 读到的内容只在本机内存里用：切句、计算阅读进度、在原文上高亮
  • 不写入任何远程位置
  • 关闭页面即消失

如果网页是 PDF，扩展会用内置的 pdf.js 解析你自己打开的那个 PDF，同样只在本机处理。

3. 什么情况下内容会离开你的电脑

只有一种：你按了空格（或点了「讲解」）。

这时扩展会把当前那一句、以及紧邻的少量上下文，发给你在「API 设置」里选择的 AI 服务。 发给谁取决于你选哪一个：

你选的后端内容发到哪里说明
浏览器内置模型（默认） 不发出去 模型跑在你本机，内容不出电脑
本地 Ollama 本机服务 发到 localhost，内容不出电脑
云端 API（你自填 key） 该服务商的服务器 受该服务商自己的隐私政策约束
我们不经手这些内容。 扩展直连你配置的服务，中间没有我们的服务器 —— 也没法经手，因为这个扩展没有后端。

4. 术语译名查证

扩展会为句子里的专业术语查询 Wikipedia，以获取标准中文译名。

  • 只发送术语本身（例如 computer vision），不发送句子、不发送上下文
  • 用的是 Wikipedia 公开 API，不需要登录，不携带任何标识
  • 查不到就如实显示「没有查到」，不会编一个译名给你

5. 本地保存了什么

以下内容存在你自己浏览器的本地存储里，不会上传：

存了什么用途怎么清除
API key / 后端地址记住你的配置「API 设置」里清空
你的术语表记住你订正过的译名同上
阅读速度基线估算每句该给多少时间重置浏览器配置即消失
已读标记记住哪句你标了「已懂」同上

卸载扩展即全部删除。

6. 权限说明

权限为什么需要
host_permissions
（全部站点）		 阅读辅助的作用对象是「你正在读的那篇文章」，而文章可能在任何网站上 —— 论文在出版商站点、预印本在 arXiv、课程材料在学校内网、技术文章在个人博客。 扩展无法预知你会打开哪个网站，所以只能声明全部站点。

但声明不等于会读：扩展不注册任何自动注入规则， 不点图标它在任何页面上都不会运行；只有你主动点击时， 才把脚本注入到当前那一个标签页。
scripting把切句与高亮脚本注入到你指定的页面
tabs判断当前标签页是不是可读的网页；侧栏模式下找到你想读的那个标签页
activeTab你点击图标时临时获得当前页访问权
sidePanel在浏览器侧栏里显示讲解

没有申请：storage、history、bookmarks、 cookies、webRequest、downloads 等任何与阅读无关的权限。

7. 儿童

本扩展不面向儿童，也不收集任何年龄相关信息。

8. 变更

如果这份政策有实质变更，会更新顶部的日期，并在扩展的更新说明里写明。
